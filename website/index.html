BEFORE YOU START

下载之前，
可能还想知道。

提供轻量 Setup 与便携 ZIP，两者都完全本地运行。下面是开始使用时最常见的几个问题。

01Kacha 会上传我的截图吗？

不会。截图、批注和剪贴板内容都在本机处理，软件不接入遥测服务。

02下载后怎么开始使用？

推荐下载 Setup 按向导安装；也可下载 ZIP 解压后直接运行 ScreenshotCat.exe。公开包支持 Windows 10 1809 及以上的 64 位系统。

03截图默认保存在哪里？

默认保存在系统“图片”目录下的 ScreenshotCat 文件夹，同时会自动复制到剪贴板。

04为什么 Windows 会显示安全提示？

当前版本尚未进行商业代码签名。请确认下载来源为本页或 GitHub Releases，并使用页面提供的 SHA-256 校验文件完整性。

05如何核对 SHA-256？

在 PowerShell 中运行：

Get-FileHash .\<下载文件名> -Algorithm SHA256
